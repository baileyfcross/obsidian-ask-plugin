# C# Assignment and Logical Operators

Assignment operators store a result in a variable. Compound forms combine an operation with assignment, while null-coalescing assignment stores a fallback only when the current value is null.

Logical operators combine or invert Boolean expressions. Conditional `&&` and `||` stop as soon as the result is known, so the right operand may not execute. This short-circuit behavior supports guarded access, such as checking that a reference is non-null before evaluating one of its members.
