# C# Bitwise and Shift Operators

Bitwise operators combine integer operands one binary position at a time. AND preserves positions set in both operands, OR preserves positions set in either, XOR preserves positions that differ, and complement reverses the bits.

Shift operators move a value's bit pattern left or right. These operations support compact flags, masks, and low-level numeric transformations. Unlike conditional logical operators, the nonconditional Boolean forms evaluate both operands, which matters when those expressions have side effects.
