# C# Boolean Type

The C# `bool` type stores one of two values, `true` or `false`. Boolean expressions are the conditions used by selection and iteration statements and are produced by comparisons, logical operators, parsing results, and many API calls.

C# does not treat arbitrary integers or objects as implicit truth values. Requiring a Boolean condition keeps control flow explicit: a program must state the comparison or predicate that decides whether a branch or loop continues.
