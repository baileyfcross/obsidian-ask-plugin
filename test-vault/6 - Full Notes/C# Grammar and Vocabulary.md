# C# Grammar and Vocabulary

C# grammar defines how tokens combine into legal statements, blocks, expressions, declarations, and comments. Vocabulary consists of the keywords, type names, member names, and identifiers used within that structure.

Methods behave like verbs because they perform actions, while types, fields, and variables act like nouns because they name kinds of things and stored values. The compiler enforces grammar, but clear naming and consistent formatting make the same valid program easier for people to understand.
