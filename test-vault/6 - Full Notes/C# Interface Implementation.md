# C# Interface Implementation

A C# interface declares capabilities a type promises to provide. Code can depend on that contract rather than a specific class, allowing different implementations to participate wherever the same operations are required.

Common .NET interfaces support comparison, enumeration, formatting, serialization, and deterministic disposal. Implementation can be public or explicit; explicit members are reached through the interface view and help separate overlapping contracts from the class's ordinary surface.
