# C# Numeric Types

C# provides signed and unsigned integer types with different bit widths, along with floating-point and decimal types for non-whole values. A type's range and precision determine which values it can represent and how much storage it uses.

`double` is efficient for scientific and general real-number computation but represents many decimal fractions approximately. `decimal` stores base-10 values with higher decimal precision and is often better for money. Numeric suffixes and explicit types prevent a literal from being interpreted with an unintended default type.
