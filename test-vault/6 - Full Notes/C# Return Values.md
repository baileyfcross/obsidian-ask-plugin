# C# Return Values

A C# function declares the type of value it returns, or `void` when its purpose is an effect rather than a result. A return statement ends the current call and supplies a value compatible with that declaration.

Returning a result lets calculation remain separate from display, storage, or user interaction. Callers can test and combine the value without repeating the function's internal logic. Several related results can be returned through a tuple when defining a separate result type would add little meaning.
