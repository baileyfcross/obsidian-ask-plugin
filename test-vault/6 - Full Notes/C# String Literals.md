# C# String Literals

A C# string literal represents text enclosed in double quotes. Escape sequences encode characters such as a newline, tab, quotation mark, or backslash, while a verbatim string suppresses ordinary escape processing and preserves path-like text more directly.

Interpolated strings embed evaluated expressions inside braces, and format specifications can control how their values appear. Verbatim and interpolated behavior can be combined when a string needs both readable literal text and inserted program values.
