# C# Unary and Binary Operators

An operator combines with one or more operands to produce or assign a value. Unary operators act on one operand, such as negation or increment, while binary operators combine two operands, such as addition, comparison, or multiplication.

The same symbol can behave differently for different operand types because types define which operations they support. Parentheses and precedence determine grouping, so explicit grouping is valuable when a compact expression could be read in more than one way.
