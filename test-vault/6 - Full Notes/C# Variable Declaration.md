# C# Variable Declaration

A C# variable declaration gives a stored value a name and a type. An assignment can initialize it with a literal, an expression, a method result, or another compatible value, and later assignments must remain compatible with the declared type.

Naming conventions communicate scope and role: local variables and private fields commonly use camel case, while types and public members use title-style casing. The `nameof` operator can retrieve an identifier's name as text without duplicating that spelling in a fragile string literal.
