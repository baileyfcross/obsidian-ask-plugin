# Algebraic Identity

An algebraic identity is an equality that holds for every permissible value of its variables. For example,

$$(x+1)^2=x^2+2x+1$$

is true for all real (x). An identity expresses two equivalent forms of the same quantity and can be used in either direction for expansion or factorization.

This differs from a [[Conditional Equation]], which holds only at its solutions. Substituting several values can illustrate an identity, but its general validity comes from algebraic properties or proof rather than a finite collection of examples.
