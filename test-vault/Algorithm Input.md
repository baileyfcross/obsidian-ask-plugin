# Algorithm Input

An algorithm's input is the data supplied for processing. It describes the particular instance of a problem: Euclid's algorithm, for example, receives two integers whose greatest common divisor is sought.

Not every [[Algorithm]] needs to receive all its data at once. An [[Online Algorithm]] accepts input incrementally and maintains a result as new items arrive. In either case, the permitted input must satisfy the algorithm's assumptions or its output may be meaningless.
