# Algorithm Output

An algorithm's output is the result produced after its steps process an [[Algorithm Input]]. The output represents the proposed solution to the problem, such as a greatest common divisor, a sorted permutation, a shortest path, or a classification.

Producing a value is not enough to establish that it is useful. The input must meet the [[Algorithm]]'s requirements, the implementation must preserve its steps, and the result must be interpreted according to the problem the algorithm was designed to solve.
